## 2. 权责确认

实现前逐项确认，不允许“原型什么都管”：

- [ ] 页面清单、信息架构、页面层级以冻结原型为准。
- [ ] 颜色、字体、圆角、阴影、状态色以设计系统 token 为准。
- [ ] 布局骨架与间距节奏以原型 1440×900 为基准，其他视口由前端定义。
- [ ] 交互路径、页签、弹层、返回路径以冻结原型为准。
- [ ] 业务规则、校验、权限以 `design.md`、`test-cases.md`、接口文档为准。
- [ ] 真实数据、数据量、状态分布以 API 与后端为准。
- [ ] 可访问性、性能、安全、浏览器兼容由前端负责。
- [ ] 组件内部 DOM 与实现以 `src/components/ui`、`src/components/console` 为准。

## 3. 必须一致

- [ ] 页面组成顺序：头部、页签、指标、表格 / 画布、分页。
- [ ] 导航与返回路径：入口、页签切换、弹层关闭、来源感知返回。
- [ ] 表格列顺序、列含义、列宽比例。
- [ ] 表单字段顺序、标签、必填标记、校验提示位置。
- [ ] 按钮层级和语义：主按钮、次按钮、危险按钮。
- [ ] 状态语义和文案：成功 / 失败 / 排队 / 待审批 / 取消。
- [ ] 共享组件选型：`DataTable`、`DetailShell`、`StatusIcon`、`OverviewMetricCards` 等。
- [ ] token 名称与值：颜色、字体、圆角、间距只来自全局主题。
- [ ] 1440×900 下的布局骨架和间距节奏。

## 4. 允许差异

每一条都必须写明理由与分类，不能留空：

| # | 差异 | 原因 | 分类 | 处理 |
|---|------|------|------|------|
| 1 | 真实数据值 / 数量不同 | 生产数据与原型样例不同 | 数据导致 | 不改代码 |
| 2 | 无 commit 时隐藏「最近克隆」 | 条件渲染 | 数据导致 | 补终态用例 |
| 3 | 单页时隐藏页码按钮 | 共享 `Pagination` 默认行为 | 实现漂移 / 产品决策 | 保持并记录 |
| 4 | 字体抗锯齿差异 | 系统渲染 | 环境差异 | 不作为失败条件 |

分类定义见 [prototype-first-standard.md](./prototype-first-standard.md) §10.5。

## 5. 数据 profile

| 状态 | Fixture / Seed | 动态区域 mask | 对应用例 |
|------|----------------|---------------|----------|
| 默认 | `<seed/default>` | 时间、头像 | `TC-...` |
| 空态 | `<seed/empty>` | — | `TC-...` |
| 加载 | `<seed/loading>` | 骨架屏 | `TC-...` |
| 失败 | `<seed/failure>` | 错误时间戳 | `TC-...` |
| 无权限 | `<seed/readonly>` | — | `TC-...` |
| 长文本 | `<seed/long-text>` | — | `TC-...` |
| 大数据量 | `<seed/dense>` | — | `TC-...` |
| 终态 | `<seed/terminal>` | 时间 | `TC-...` |

要求：

- 生产数据不得作为视觉基线。
- 动态时间、头像、实时日志、随机数必须 mask 或固定值。
- 每个状态必须能通过固定 URL / 路由参数直达。

## 7. 共享组件对账

写页面前完成，避免实现阶段才发现默认值冲突：

| 原型控件 | 共享组件 | 默认行为差异 | 决策 | 影响页面 |
|----------|----------|--------------|------|----------|
| `<控件>` | `OverviewMetricCards` | `xl:grid-cols-6` | 增加 `columns` 参数 | 详情页 |
| `<控件>` | `Pagination` | 单页隐藏页码 | 保持全局行为 | 全部列表 |

冲突处理优先级：复用现有组件 → 给共享组件增加参数 → 页面级覆盖 → 新增共享组件。禁止在业务页复制私有皮肤。

## 10. 变更控制

- 冻结后修改原型必须升版、重新评审，并更新本契约。
- 实现阶段发现规格问题：先改原型与 `prototype-spec.json`，再改代码。
- 禁止实现完成后追认式修改原型去对齐代码而不升版、不评审。
- 纯样式豁免必须记录修改前后截图、对齐等级与偏差分类，不得借豁免修改信息结构或交互。
