## 第 1 轮 · 2026-10-22 · 原型改造

- **状态**：原型已实现
- **触发**：用户要求「事项详情效果修改为弹窗」，并确认形态为居中大弹窗、只保留列表参数、本轮只改原型

### 做了什么

1. 详情从 `#/items/:id` 独立页改为 `#/workbench?detail=<id>` 叠加弹窗，新增遮罩、顶部条与独立滚动区。
2. 详情状态参数改 `dstate`、页签改 `dtab`，避免与列表 `state`/视图配置 `tab` 冲突。
3. 新增 `closeDetail()`：关闭只清详情参数，保留视图/搜索/筛选/分页。
4. 全部详情链接（列表标题、快速预览、总览 chip、原型导航）迁移到新 URL。
5. 重出 01、28–48、51、53、54 号画板；同步 spec/README/契约。

### 验证

| 检查 | 结果 |
|---|---|
| 脚本语法 | `node --check` 通过 |
| 关键状态截图 | 默认、编辑、校验、只读、页签、内联、流转弹层、404、加载、失败、1280 均正常 |
| 关闭行为 | URL 去详情参数，列表保持（含 `type=bug&page=2`） |
| URL 冒烟 | 16 个 URL 全部正常，0 页面异常 |

### 决策与取舍

- **决策**：详情状态用 `dstate`、页签用 `dtab`。**理由**：同一 URL 上列表与详情都有 `state`/`tab`，不复用可避免打开详情时列表进入空态/错误态。
- **决策**：保留弹窗内 404/加载/失败态。**理由**：深链与接口异常都需要就地反馈。

### 未完成 / 风险

- `frontend/` 未改，实现与 v1.10 冻结原型仍是独立详情页；需下一轮对齐。
- v1.11 原型待评审冻结。

### 下一步

- **唯一动作**：用户评审 v1.11 弹窗原型，确认后重新冻结并安排实现。
