## 第 1 轮 · 2026-10-22 · 原型改造

- **状态**：原型已实现，实现未开始
- **触发**：用户标注「header 是全局的，左侧是对应产品下的菜单，右侧是展示对应菜单内容」

### 做了什么

1. `.app` 改为纵向 flex，新增 `.app-body` 承载侧栏 + 内容；`main` 独立滚动。
2. header 提到 shell 顶层，跨全屏；品牌块从侧栏移入 header 左侧，新增分隔线。
3. 侧栏移除品牌，顶部直接是项目/产品切换。
4. 原型升 v1.12，重出全部 54 张画板；同步 spec/README/契约。

### 验证

| 检查 | 结果 |
|---|---|
| `node --check` | 通过 |
| 列表 / 总览 / 详情弹窗 | 共用全局 header，无横向溢出 |
| 1280×800 | header 单行，搜索与账号不换行 |

### 决策与取舍

- **决策**：品牌从侧栏移入 header。**理由**：header 全局后，左侧需要归属标识；侧栏只承担产品菜单职责。
- **决策**：内容区独立滚动。**理由**：header 与菜单常驻，符合后台控制台习惯。

### 未完成 / 风险

- `frontend/` 未改，React 仍是「侧栏 + 内容区 header」；实现需重构 `AppShell` 与 shadcn Sidebar 的层级。
- v1.12 原型待评审冻结。

### 下一步

- **唯一动作**：用户评审 v1.12 布局，确认后安排实现。
