## 1. 原型用例

| 编号 | 步骤 | 输入 | 预期 | 验证方式 |
|---|---|---|---|---|
| TC-01 | 打开列表 | `#/workbench` | header 横跨全屏；品牌在 header 左侧；侧栏从 header 下方开始 | 画板 02 |
| TC-02 | 面包屑 | 进入列表/设置/总览 | 面包屑随页面变化，位于品牌右侧 | 画板 02、22、01 |
| TC-03 | 产品菜单 | 左侧导航 | 顶部为项目切换，依次为原型总览、工作项类型、协作、配置；无品牌块 | 画板 02 |
| TC-04 | 内容滚动 | 列表 13 页 / 长文本 | 仅内容区滚动，header 与侧栏不滚动 | 手工 |
| TC-05 | 详情弹窗 | `?detail=1` | 弹窗遮罩覆盖全屏（含 header），关闭后布局不变 | 画板 28 |
| TC-06 | 1280 视口 | 1280×800 | header 单行、搜索与账号不换行；侧栏保持 256px | 画板 52–54 |
| TC-07 | 总览页 | `#/overview` | 同一 header 与侧栏结构，内容区为总览 | 画板 01 |

## 2. 实现用例

| 编号 | 步骤 | 输入 | 预期 | 自动化位置 |
|---|---|---|---|---|
| TC-08 | 全局 header | 任一路由 | header 位于 `sidebar-inset` 之外且在侧栏之前；含产品切换、搜索、帮助、通知、主题、用户菜单 | `AppShell.test.tsx::keeps one shell and swaps the sidebar to the current product` |
| TC-09 | 产品名上提 | `/pm/projects`、`/container/clusters`、`/api-test` | 当前产品名出现在 header；侧栏不含产品名/「产品选择」 | 同上 |
| TC-10 | 侧栏只放菜单 | 切换产品路由 | 侧栏随产品切换菜单，不含产品切换器；固定容器带 `top-(--header-height)` 与 `!h-[calc(...)]` | 同上 |
| TC-11 | 面包屑去重 | `/container/clusters` | 面包屑只剩产品内路径（集群），首项为当前项 | 同上 |
