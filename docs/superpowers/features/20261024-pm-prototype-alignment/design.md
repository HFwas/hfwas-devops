## 1. 背景与目标

2026-10-24 独立 agent 以 Playwright 对 `http://localhost:8000`（admin/admin123）逐页逐状态对照冻结原型 v1.13，产出 37 条偏差：阻塞 2、高 8、中 15、低 10、数据导致 1，另有 3 处契约内部冲突。

本轮目标：关闭**阻塞项与实现漂移类高优先级项**，并把「原型冲突」按用户裁决固化，使列表工作台与事项详情弹窗回到可验收状态。

## 2. 用户决策（本轮生效）

1. **无权限态暂不考虑。** 不实现只读成员模式与「只读态仅导出」，整页「无权访问」保持现状；审计中的无权限相关偏差（#23）本轮不关闭。
2. **批量栏位置以冻结画板 10 为准。** 改为工具栏下方整宽内联条 + 选中行高亮，不再使用底部悬浮胶囊。原型契约正文「底部批量栏」的措辞按本决策更正。

## 4. 非目标（本轮明确不做）

- 视图与搜索设置页、批量操作配置页、动作编辑弹层、侧栏「协作」「配置」两组入口（依赖上述页面）。
- 导入向导、导出弹层、快速预览、批量栏导出动作。
- 无权限/只读模式（用户决策 1）。
- 状态流转由下拉改为居中弹层（画板 33）、批量编辑影响预览常驻、类型图标独立语义色。
- 原型过期项（产品下拉 8→12、`/pm/projects` 无画板）不改代码，写回文档。

## 5. 关键实现点

1. **详情弹窗结构**：`WorkItemDetailDialog` 拆为
   - `DetailHeader`（编号/类型/复制链接、标题与操作、状态元信息、页签）；
   - 左栏按 `tab` 渲染 描述 / 操作记录 / 评论；
   - 右栏 `PropertyPanel` 常驻。
   编辑态仍只允许详情页签。
2. **筛选提交**：`FilterBuilder.apply()` 只调用一次 `onApply`；`onApply` 内部同时清 `overlay`。禁止再调用 `onOpenChange(false)` 触发第二次提交。
3. **列目录**：`SYSTEM_COLUMNS` 增加 `storyPoints`（故事点，数字）与 `risk`（风险等级，枚举）的显示元数据。二者默认不可筛选/不可排序——当前项目没有对应 `pm_field_definition`，走 `custom.*` 会被后端拒绝；`buildColumnCatalog` 在发现同名自定义字段定义时自动合并 `filterable/sortable/queryField`，后端补齐定义后无需改前端。
4. **保存视图**：新增 `SaveViewDialog`，默认名 `<当前视图名> · 我的配置`，提交后切换 `view=<newId>` 并清空覆盖参数。
5. **右栏字段**：按固定顺序渲染，值来源为系统字段或 `customFields`，空值按字段语义显示（未设置 / 未分配 / 未归属 / 无父事项）；已有内联控件（优先级/负责人/截止时间/模块）保留，其余本轮只读。
6. **批量栏**：`BulkActionBar` 增加 `inline` 形态；PM 列表内联渲染在工具栏之后，`DataTable` 选中行使用 `bg-primary/10`。

## 6. 兼容性与迁移

- 纯前端改动，无数据库迁移、无接口变更。
- URL 参数兼容：不新增必填参数；`overlay=save-view` 仅用于打开命名弹层。
- 既有 `BulkActionBar` 调用方仅 PM 列表，改为内联不影响其他模块。

## 7. 验收标准

1. 详情弹窗在「操作记录」「评论」页签下仍显示标题、页签与右栏属性，可切回详情。
2. 应用「我的工作项」后 URL 出现 `f=`，列表请求体携带条件，总数与条件行同步更新。
3. 1440×900 下「保存配置」完整可见，抽屉内容可独立滚动。
4. 侧栏全部工作项计数等于各类型数量之和（当前为 1）。
5. 表头显示「故事点」，视图配置不再出现「字段缺失」；故事点/风险等级的筛选与排序待后端字段定义就绪后自动开放。
6. 可从页签行保存新视图并在页签中选中。
7. 详情右栏 15 项字段齐备，空值按字段语义显示（未设置 / 未分配 / 未归属 / 无父事项），无重复模块行。
8. 编辑态取消弹出确认；校验失败有顶部汇总。
9. 空态有「新建工作项」主按钮；加载态保留表头与 8 行骨架。
10. 选中行后批量条位于工具栏下方、整宽、含「已选当前页 N 项」，行高亮明显。
