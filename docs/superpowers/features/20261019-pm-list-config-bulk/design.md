## 1. 背景与目标

### 1.1 现状

- PM 已有两个原型：工作台列表（`20261019-pm-workbench-redesign`）与事项类型（`20261019-pm-work-item-types`），但分散在功能目录，没有模块级总入口。
- 项目启用类型只体现在列表页顶部按钮，没有进入左侧导航；用户无法一眼看到项目里有哪些类型、各有多少事项。
- 列表列、搜索字段、筛选项仍然是页面写死或只读取默认布局，没有让用户按角色保存视图。
- 导入/导出已有后端接口，但缺少完整的前端流程；批量修改字段没有后端接口，也没有操作配置。
- 批量操作没有权限、条数上限、二次确认与字段白名单的统一配置。

### 1.2 目标

| 编号 | 目标 | 可验证结果 |
|------|------|-----------|
| G1 | PM 模块单一原型入口 | `docs/product/06-prototype/pm/#/overview` 收敛全部 PM 原型与页面 |
| G2 | 项目类型进入左侧导航 | 左侧按项目启用方案展示全部类型与数量，点击即筛选 |
| G3 | 列表字段可配置 | 显示列、顺序、密度、默认排序可配置并保存为视图 |
| G4 | 搜索字段可配置 | 搜索框只匹配勾选的字段，工具条显示搜索范围 |
| G5 | 批量操作可配置 | 操作启停、角色、单次上限、二次确认、字段白名单可配置 |
| G6 | 批量修改闭环 | 选字段 → 设值 → 预览影响 → 确认 → 展示成功/跳过/失败 |
| G7 | 导入导出完整 | 导入模板 → 映射 → 校验 → 执行；导出按选中/查询/全部与字段集 |
| G8 | 状态完整 | 默认/空/加载/失败/无权限/大数据/长文本/校验失败全部可直达 |

### 1.3 非目标

- 不实现看板列映射、迭代燃尽、工时与自动化规则；
- 不实现字段定义的新建/编辑（继续由事项类型与字段配置页负责）；
- 不实现跨项目批量操作；
- 不实现服务端异步导出任务（首版同步导出，超限给出提示）；
- 不实现批量操作的回滚 UI（首版只记录审计与结果明细）。

## 2. 成熟产品调研

| 产品 | 关键能力 | 借鉴点 |
|------|----------|--------|
| **Jira** | Issue Type Scheme 决定项目可用类型；Issue Navigator 的 Columns 配置；Bulk change 先选操作再勾选字段，最多 1000 条；字段必须在所有选中事项的字段配置中可见 | 类型方案驱动导航；批量编辑只展示共同可用字段；操作前预览与权限校验 |
| **Linear** | `X` 选中、`Shift` 连选、`Cmd/Ctrl+A` 全选；底部浮动批量栏；Advanced filter 支持嵌套条件组与 AND/OR；API `issueBatchUpdate` 最多 50 条 | 底部批量栏；高级筛选的条件组与根逻辑 |
| **Notion** | 数据库筛选支持 `and` / `or` 复合条件，API 最多 2 层嵌套；操作符按属性类型变化（文本、数字、日期、选择、人员） | 按字段类型提供操作符；限制嵌套层数，避免不可读 |
| **Airtable** | 筛选组支持 And / Or，一个组只能一种关系，最多 3 层；单值/多值/日期/数字操作符不同；推荐用 `isAnyOf` 代替多个 OR | 根逻辑 + 条件组；按字段类型提供 `属于/不属于` 等批量操作符 |
| **GitHub Projects** | 表格视图 = 数据库；自定义字段（文本/数字/日期/单选/迭代）；视图保存布局、筛选、排序、分组；表格多选后批量设置字段；issue side panel 可直接编辑自定义字段并记录活动 | 视图配置与批量编辑在同一表格上下文；详情侧栏直接编辑字段 |
| **OpenProject** | 表格右键 Bulk edit / move / duplicate / delete；CSV 导入模板、字段映射、先校验后导入、错误明细；自定义字段需按类型与项目启用 | 导入向导三段式；批量操作收敛在表格与右键菜单 |
| **YouTrack** | 自定义字段全局/项目级顺序；列表列可配置；搜索后 `Ctrl+A` 批量执行命令；可关闭通知 | 字段显示顺序与可见性配置；批量执行可配置通知 |
| **Plane** | 开源 Jira/Linear 替代；Issue Types + 每类型自定义属性；批量操作与周期批量关联 | 类型与属性绑定；开源实现可参考数据模型 |
| **PingCode** | 工作项类型与属性配置；表格/看板批量操作；导入导出；导出上限 5000 条 | 类型分组与项目模型；导出上限与字段选择 |
| **Jira 新版 Issue View** | 两栏布局，点击字段即可内联编辑；评论栏常驻；活动与评论分开；字段可固定/折叠 | 双栏 + 内联编辑 + 活动/评论分栏 |
| **Linear Issue Detail** | 标题与描述点击即编辑并自动保存；右侧属性栏；评论与内联评论；键盘优先 | 标题/描述内联编辑；属性栏收敛；自动保存与显式保存并存 |
| **Plane Work Item Detail** | 高频属性（状态/优先级/负责人/日期）放在标题下方中栏；属性分组折叠；活动流筛选；静态元数据下沉到页脚 | 高频字段前置；右栏分组；活动流与评论统一时间线 |

结论：

1. **类型导航**必须来自项目启用方案，而不是前端常量。
2. **列、搜索、筛选**应统一收敛为「视图配置」，与保存视图一起持久化。
3. **批量操作**不是一个按钮，而是一组可配置动作：角色、上限、确认、字段白名单、结果明细。
4. **导入**必须走「模板 → 映射 → 校验 → 执行」，不能直接上传即写库。
5. **导出**必须允许选择范围与字段集，并显示条数上限。

## 4. 功能设计

### 4.1 项目启用类型导航

- 数据来源：`POST /pm/projects/issue-types/list`，顺序按项目 scheme。
- 左侧「工作项」分组默认展开，展示：全部工作项 + 每个启用类型的名称与数量。
- 内置类型与自定义类型使用不同图标/来源标记；停用类型不显示。
- 点击类型写入 URL `type=requirement`，列表查询带 `typeCode`，页头与页签同步。
- 「管理事项类型」跳转事项类型页；无权限时隐藏。
- 类型数量来自列表接口聚合；首版可在进入项目时批量查询。

### 4.2 视图配置（显示列 / 搜索字段 / 筛选字段）

入口：工具栏「显示」。

| Tab | 配置项 | 行为 |
|-----|--------|------|
| 显示列 | 勾选字段、上移/下移、恢复默认；密度（标准/紧凑）；默认排序 | 保存后立即重绘表格；字段顺序即列顺序 |
| 搜索字段 | 勾选参与搜索的字段（标题、编号、负责人、描述、自定义字段） | 搜索框提示与匹配范围同步；至少保留 1 个 |
| 筛选字段 | 勾选筛选面板可用的字段 | 筛选面板只展示勾选字段 |

- 配置与筛选、排序一起保存为视图（`PmSavedView.querySpec` + `columns`）。
- 用户视图与项目共享视图分开；共享视图需管理员权限。
- 视图被修改后页签显示脏标记，提供「保存」「另存为」「重置」。

### 4.2.1 筛选构建器（AND / OR / 条件组）

入门：工具栏「筛选」。

结构：

```text
根条件关系：AND / OR
├─ 条件：状态 属于 [进行中, 已阻塞]
├─ 条件：优先级 属于 [最高, 高]
└─ 条件组（OR）
   ├─ 负责人 是 陈思远
   └─ 负责人 是 林小满
```

规则：

1. 字段来自视图配置的「筛选字段」，不可超出该集合。
2. 根级与每个条件组各自只能选择一种关系（AND 或 OR），不能混用。
3. 条件组最多嵌套 1 层（根 + 组），对齐 Notion API 的 2 层限制，避免表达式不可读。
4. 操作符按字段类型变化：

| 字段类型 | 操作符 |
|----------|--------|
| 文本（标题、描述、编号） | 包含、不包含、等于、不等于、为空、不为空 |
| 枚举（状态、优先级、风险、迭代） | 属于、不属于、是、不是、为空、不为空 |
| 用户（负责人） | 是、不是、属于、不属于、为空、不为空 |
| 日期（截止时间） | 等于、早于、晚于、在区间、今天、本周、为空 |
| 数字（故事点） | 等于、大于、小于、大于等于、小于等于、在区间、为空 |

5. 值编辑器随操作符变化：
   - `属于 / 不属于`：多值 chip 选择，可增删；
   - `是 / 不是 / 等于`：单选或输入；
   - `在区间`：两个输入；
   - `为空 / 不为空 / 今天 / 本周`：无需填写值。
6. 条件组可单独删除；条件可单独删除；根条件与组之间显示 AND/OR 分隔线。
7. 实时展示「预计匹配 N 条」与表达式预览，例如：
   `状态 属于 进行中、已阻塞 AND 优先级 属于 最高、高 AND (负责人 是 陈思远 或 负责人 是 林小满)`。
8. 存在缺值条件时禁止应用，给出顶部汇总；修正后自动清除错误。
9. 快速筛选提供：我的工作项、本周到期、阻塞风险、未分配。
10. 首版不提供原始 JQL / 表达式编辑，只提供可视化构建器；高级表达式预览只读。

与 `QuerySpec` 的映射：

```json
{
  "logic": "AND",
  "conditions": [
    { "field": "status", "operator": "IN", "value": ["in_progress", "blocked"] },
    { "field": "priority", "operator": "IN", "value": ["highest", "high"] }
  ],
  "groups": [
    {
      "logic": "OR",
      "conditions": [
        { "field": "assignee_id", "operator": "EQ", "value": "陈思远" },
        { "field": "assignee_id", "operator": "EQ", "value": "林小满" }
      ]
    }
  ]
}
```

- `IN` / `NOT_IN` 直接映射到数组值。
- `EMPTY` / `NOT_EMPTY` 对应 `IS_NULL` / `IS_NOT_NULL`。
- 日期 `BEFORE` / `AFTER` / `BETWEEN` 对应 `LT` / `GT` / `BETWEEN`。
- 前端提交前把枚举显示值转换为字段 optionKey。

### 4.3 搜索

- 输入防抖 350ms；匹配范围由「搜索字段」决定。
- 搜索框右侧显示范围 chip，如「4 个字段」，悬停展示具体字段。
- 无结果空态保留筛选条件，提供清空搜索。
- 搜索条件写入 URL `q`，刷新与分享不丢失。

### 4.4 批量操作

#### 4.4.1 动作清单

| 动作 | 是否需要选择 | 说明 |
|------|--------------|------|
| 批量编辑字段 | 是 | 选字段 → 设值 → 预览 → 确认 |
| 批量状态流转 | 是 | 按工作流校验，不允许的流转跳过并提示 |
| 复制事项 | 是 | 复制标题、描述、字段；可指定目标类型 |
| 导出所选 | 是 | 选择字段集，导出 Excel |
| 删除事项 | 是 | 危险操作，二次确认写明数量 |
| 导入事项 | 否 | 模板 → 映射 → 校验 → 执行 |

#### 4.4.2 批量编辑字段

- 可选字段来自批量操作配置的字段白名单，且对所有选中事项可见。
- 支持「设置为…」与「清空值」。
- 字段类型驱动编辑器：单选/状态/优先级 → 下拉；负责人 → 用户选择；日期 → 日期；数字 → 数字；多选 → 多选。
- 提交前预览：受影响 N 项、将跳过 M 项（工作流不允许/无权限）、示例前 3 行。
- 提交后展示结果：成功 / 跳过 / 失败，可下载失败明细。
- 单次上限由配置决定（默认 100，最大 1000）。

#### 4.4.3 导入

三段式：

1. **上传**：选择类型、下载模板、选择文件、导入模式（新建 / UPSERT）、字段集。
2. **映射**：检测表头 → Excel 列映射到系统字段；必填缺失、类型不匹配、重复列实时提示。
3. **校验与执行**：总行数、有效行、警告、错误；先校验后导入；执行后展示新建/更新/跳过/失败。

约束：

- 仅项目管理员或具备「导入事项」权限的角色可用。
- 单次行数上限由配置决定（默认 5000）。
- 失败行不影响已成功行（首版），结果页提供错误明细下载。
- 文件编码 UTF-8；模板列顺序固定，允许列增删。

#### 4.4.4 导出

- 范围：选中项 / 当前查询结果 / 全部。
- 字段集：默认取导出配置，可在弹层增删；至少 1 个字段。
- 显示预计条数与上限；超限禁用导出并提示缩小范围。
- 格式：Excel（首版）。

### 4.5 批量操作配置

页面：`/pm/projects/:projectId/settings/bulk-actions`，仅项目管理员可见。

| 配置项 | 说明 |
|--------|------|
| 动作启停 | 每个动作独立开关；关闭后批量栏不出现 |
| 允许角色 | 项目管理员 / 项目成员 / 只读成员（只读永不出现） |

| 默认导出字段 | 导出弹层默认勾选 |
| 默认导入模式 | CREATE / UPSERT |

### 4.6 权限与安全

- 只读成员只能搜索、筛选、导出（若允许），不能编辑、删除、导入。
- 批量编辑只能修改字段白名单中的字段；状态流转走工作流校验。
- 删除必须二次确认，且默认关闭，需要管理员显式开启。
- 导出包含敏感字段（如自定义密钥类字段）时需单独授权（首版不导出敏感字段）。
- 所有批量操作写审计日志，失败明细可下载。

### 4.8 事项详情

入口：列表标题、行「预览」抽屉的「打开完整详情」。

布局：

```text
返回 / 编号 / 类型 / 复制链接
标题（点击或「编辑」进入编辑态）               [状态流转] [编辑] [删除]
状态 / 优先级 / 风险 / 更新时间 / 迭代
详情 | 操作记录 5 | 评论 3
┌──────────────────────────────┬────────────────┐
│ 当前页签内容                 │ 属性（可编辑）  │
│ 详情：描述（查看 / 编辑）     │ 状态 / 优先级   │
│ 操作记录：时间线             │ 负责人 / 截止   │
│ 评论：列表 + 输入             │ 迭代 / 故事点   │
│                              │ 风险 / 标签     │
└──────────────────────────────┴────────────────┘
[未保存的更改]                    [取消] [保存修改]
```

页签规则：

- 页签固定在标题与属性行下方、内容区上方，默认「详情」。
- 「操作记录」「评论」不再是描述卡片的内部页签，长描述不会把它们压到页面底部。
- 右栏属性在所有页签保持可见，便于跨页签编辑。
- 编辑态只保留「详情」页签，并显示「编辑中 · 保存后可查看操作记录与评论」，避免切换页签丢失未保存内容。

规则：

1. **双栏**：左侧内容（标题、描述、活动、评论），右侧属性（高频字段）。
2. **两种编辑方式**：
   - 阅读态点击标题/描述/属性行进入编辑态；
   - 顶部「编辑」进入完整编辑态，底部出现保存条。
3. **高频属性前置**：状态、优先级、负责人、截止时间、迭代、故事点、风险、标签在右栏，顺序固定。
4. **标题**：必填，2–120 字符；空标题阻止保存。
5. **描述**：多行文本，支持 Markdown；编辑态显示 textarea，阅读态渲染段落。
6. **状态流转**：只展示工作流允许的目标状态；流转前校验必填字段与后置函数；成功后记录活动。
7. **活动与评论**：
   - 活动记录：创建、状态变更、负责人变更、关联、评论等；
   - 评论：列表 + 输入框，支持 @ 提及与 Markdown；
   - 首版活动与评论分页签，不合并时间线。
8. **校验**：标题为空、故事点 ≤ 0 时显示顶部汇总与字段级错误；保存失败保留编辑态。
9. **未保存确认**：编辑态返回或取消时弹出「放弃未保存的修改？」。
10. **权限**：只读成员隐藏编辑、状态流转、删除、评论输入，属性栏标注「只读」。
11. **删除**：危险操作二次确认，删除后返回列表。
12. **加载/失败**：加载态展示骨架；失败态提供重试与返回列表。

单字段内联更新：

1. 阅读态点击字段直接打开内联编辑器，不需要先进入完整编辑态。
2. 所有业务字段均支持单字段更新：
   - 标题：标题位置直接变为输入框，保存/取消；
   - 描述：描述卡片内打开 Markdown 编辑器，保存/取消；
   - 状态、优先级、类型、负责人、报告人、迭代、风险、修复版本、模块、父事项：选项菜单，当前值标记「当前」，选中即保存；
   - 截止时间：日期输入 + 保存；
   - 故事点：数字输入 + 保存；
   - 标签、环境：文本输入 + 保存；
   - 关注者：多选切换，添加/移除后即时保存。
3. 系统字段（编号、创建时间、更新时间）只读，不在单字段更新范围。
3. 状态更新走工作流校验：
   - 只允许当前状态的合法目标；
   - 不允许的状态置灰并标注「工作流不允许」；
   - 提交后记录到操作记录。
4. 交互反馈：
   - 选择后立即更新界面（乐观更新），显示「已保存」toast；
   - 失败时回滚到旧值并提示原因；
   - 点击外部或 Esc 关闭，不保存。
5. 操作记录：
   - 每次字段更新追加一条操作记录，记录操作人、字段旧值/新值、时间；
   - 状态变更记录「将状态从「进行中」改为「待验证」」；
   - 完整编辑保存时逐字段对比，每个变更各记一条；
   - 评论发表追加「添加了评论」；
   - 操作记录页签的数量实时更新。
6. 操作记录分页：
   - 默认最新在前，第一页展示最新记录；
   - 每页 5 / 10 / 20 条，默认 5 条；
   - 显示总条数、当前页/总页数、上一页/页码/下一页；
   - 新增记录后回到第一页可看到最新记录；
   - 页码与每页条数写入 URL（`actPage`、`actSize`），刷新保持。
7. 完整编辑态保留，用于多字段一起保存；标题/描述也可通过单字段编辑器修改。
8. 单字段接口建议：`PATCH /pm/work-items/{id}/fields`，请求体 `{ field, value, version }`；状态字段由服务端再做一次工作流校验；类型变更需额外校验字段/工作流兼容性。
9. 权限：只读成员不能打开内联编辑器；状态选项仍需服务端校验。

Markdown 描述：

1. 阅读态渲染 Markdown：标题、加粗/斜体、删除线、链接、有序/无序列表、任务列表、引用、代码块、表格、分隔线。
2. 编辑态提供「编辑 / 预览」页签：
   - 编辑：等宽字体 textarea，底部/顶部工具栏支持 H、B、I、行内代码、链接、列表、任务列表、引用；
   - 预览：使用当前 textarea 内容实时渲染，不触发页面重渲染，避免丢失未保存内容。
3. 字符数实时显示；保存时存 Markdown 源文本，不做 HTML 存储。
4. 安全：先 HTML 转义再渲染；只允许 `http://`、`https://`、`mailto:` 链接；不支持原始 HTML 与脚本。
5. 评论与快速预览共用同一渲染器，保证展示一致。
6. 富文本工具栏、@ 提及、图片上传不在首版范围；后续接入统一编辑器时保持 Markdown 源文本兼容。

接口映射：

| 场景 | 接口 |
|------|------|
| 详情 | `GET /pm/work-items/{id}`（现有详情接口） |
| 保存字段 | `POST /pm/work-items/save`（携带 id 与变更字段） |
| 状态流转 | `POST /pm/work-items/transition`（目标状态 + 校验） |
| 评论 | `POST /pm/work-items/comments` |
| 活动 | `GET /pm/work-items/{id}/activities` |

并发：

- 保存时携带 `updateTime` 或版本号，服务端做乐观锁；冲突时提示刷新并保留本地草稿。
- 评论与字段编辑分开提交，避免评论失败阻塞字段保存。

## 9. 风险与待确认

| 风险 | 影响 | 应对 |
|------|------|------|
| 后端无批量更新接口 | 大批量效率低 | 首版限制 50 条逐条调用，接口就绪后切换 |
| 字段可见性/权限差异 | 批量字段在某些事项不可用 | 后端返回可编辑字段交集；前端预览跳过项 |
| 工作流限制 | 部分状态不可直接流转 | dry-run 校验 + 跳过明细 |
| 导入部分成功语义 | 用户误解 | 明确提示成功/失败行；提供明细下载 |
| 视图配置与字段布局职责重叠 | 两处配置冲突 | 字段布局提供默认值，视图配置做覆盖 |
| 类型数量聚合性能 | 左侧每次加载慢 | 进入项目时一次聚合，切换类型不重复请求 |
| 组合筛选项过多导致不可读 | 用户难以理解条件 | 限制 2 层嵌套；提供表达式预览与 chip 摘要 |
| 枚举显示值与 optionKey 不一致 | 查询结果错误 | 前端维护映射表；提交前转换，必要时由字段接口返回选项 |
| 详情并发编辑冲突 | 覆盖他人修改 | 乐观锁 + 冲突提示 + 保留草稿 |
| 富文本/Markdown 渲染安全 | XSS | 统一渲染器做白名单过滤；评论与描述同策略 |
| 评论与字段保存耦合 | 部分失败 | 分开提交，分别提示 |
| 单字段乐观更新冲突 | 覆盖他人修改 | 携带版本号；冲突回滚并提示刷新 |
| 内联编辑器遮挡 | 小屏/长列表 | 底部字段弹层向上展开；滚动时关闭 |
| 类型变更影响字段/工作流 | 数据不一致 | 生产二次确认，服务端校验类型兼容性 |
