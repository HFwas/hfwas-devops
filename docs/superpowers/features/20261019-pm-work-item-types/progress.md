### 决策与取舍

- **决策**：类型管理放在项目设置下，而不是全局管理台。**理由**：项目启用方案本身就是项目级配置，用户从项目上下文进入最自然；全局创建影响范围在摘要与弹层中明示。**未选方案**：独立平台管理后台。
- **决策**：内置类型名称与 code 只读，只允许配置字段与工作流。**理由**：对齐 PingCode 内置类型规则，避免历史事项语义漂移。
- **决策**：新建采用四步向导，不做单页长表单。**理由**：字段、工作流与预览信息量大，分步降低认知负担，也便于逐步校验。
- **决策**：删除被引用时直接阻止并提供「停用」。**理由**：对齐 Jira / PingCode，避免历史数据失联。
- **决策**：本轮不写 `test-cases.md` 与 `changes.md`。**理由**：规范要求原型冻结后再进入测试用例与编码。
