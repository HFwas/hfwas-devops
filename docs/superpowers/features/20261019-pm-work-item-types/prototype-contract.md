## 3. 必须一致（A2）

- [x] 列表页顺序：页头 → 指标条 → 页签 → 工具栏 → 表格。
- [x] 侧栏 256px、顶栏 56px、内容区 24px 边距。
- [x] 表格列顺序：类型、来源、启用状态、字段、工作流、使用中、顺序、操作。
- [x] 表格行高 52px。
- [x] 内置类型带锁标识且无删除入口；自定义类型有复制、停用、删除。
- [x] 编辑器三栏：步骤 176px、主面板、摘要 268px。
- [x] 步骤顺序：基本信息 → 字段与布局 → 工作流 → 预览。
- [x] 左侧步骤当前态、已完成态与可点击跳转。
- [x] 右侧摘要展示名称、code、来源、模板、字段数、工作流、启用范围。
- [x] 危险操作文案写明后果，删除被阻止时提供停用替代。
- [x] 1440×900 下基本信息步骤与字段步骤无需页面级滚动。

## 4. 允许差异

| # | 差异 | 原因 | 分类 | 处理 |
|---|------|------|------|------|
| 1 | 使用量、字段数、描述为样例 | 后端暂未返回 | 数据导致 | 实现接真实接口，缺省显示 `—` |
| 2 | 内置标识原型用常量判断 | 接口无 `builtIn` | 实现漂移 | 后端补字段前用 5 个 code 兜底 |
| 3 | 模板切换未弹确认框 | 原型简化 | 产品决策 | 实现按 O06 弹确认 |
| 4 | 项目启用范围排序未持久化 | 原型无后端 | 数据导致 | 实现保存 scheme 顺序 |
| 5 | 暗色下类型图标底色加深 | token 设计 | 环境差异 | 以 token 为准 |
| 6 | 字体抗锯齿与系统回退 | 渲染环境 | 环境差异 | 不作为失败条件 |
| 7 | 「从模板创建」复用复制弹层 | 原型简化 | 产品决策 | 实现可用同一组件换标题 |
| 8 | 字段拖拽以上移/下移替代 | 原型零依赖 | 实现漂移 | 生产用 dnd-kit，保留上下移兜底 |

## 7. 共享组件对账

| 原型控件 | 共享组件 | 默认行为差异 | 决策 | 影响页面 |
|----------|----------|--------------|------|----------|
| 指标条 | `OverviewMetricCards` | 现有卡片偏大，4 项 | 增加紧凑变体或页面级 4 列网格 | 类型列表 |
| 类型表格 | `DataTable` | 行高 44、无开关列 | 新增 `rowHeight` 可选 prop；开关用单元格自定义渲染 | 类型列表 |
| 开关 | 无 `switch.tsx` | 当前 `ui` 目录无 Switch | `npx shadcn add switch` | 列表、编辑器 |
| 内置标识 | 无 | — | 新增 `BuiltinBadge` | 列表 |
| 类型图标 | `StatusIcon` 面向运行状态 | 语义不同 | 新增 `TypeIcon`，颜色仍走 token | 列表、编辑器 |
| 编辑器步骤 | 无 | — | 新增 `TypeEditorShell` | 新建/编辑 |
| 字段布局 | 无 | — | 新增 `FieldLayoutTable` | 字段步骤 |
| 工作流预览 | 无 | — | 新增 `WorkflowPreview` | 工作流、预览 |
| 抽屉 | `Sheet` 已存在 | 宽度默认 384 | 传 `className` 覆盖为 520 | 项目范围 |
| 空/失败/无权限 | 与工作台改版共享 | 尚未落地 | 先在工作台功能实现，本功能复用 | 列表 |
| 复制/删除确认 | `Dialog` / `AlertDialog` / `ConfirmDialog` 已存在 | 无 | 直接复用 | 弹层 |

冲突处理顺序：复用现有组件 → 增加可选 props → 页面级覆盖 → 新增共享组件。
