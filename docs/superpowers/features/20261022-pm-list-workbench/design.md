## 1. 背景与目标

阶段 1 已完成后端增量接口和共享列表组件。当前列表页仍是旧实现，无法按原型提供视图、筛选、列配置与批量操作。

本阶段目标：

- 「全部工作项」入口与项目类型计数；
- URL 驱动的列表状态（视图、搜索、列、搜索字段、筛选字段、密度、排序、分页、选择、弹层）；
- 四个内置视图与已保存视图、视图配置抽屉；
- 搜索、两层级筛选构建器、排序、分页；
- 当前页选择与批量编辑 / 批量流转 / 批量删除。

非目标见 `pm-design.md` §1.4 与实施计划；导入导出、保存视图弹层、快速预览、设置页与详情页留到后续。

## 3. URL 契约

路由沿用 `/pm/projects/:projectId/items/:typeCode`；`typeCode=all` 表示全部工作项，查询时省略 `typeCode`。

| 参数 | 取值 | 默认 |
|---|---|---|
| `view` | `dev` / `mine` / `week` / `blocked` / 已保存视图 id | `dev` |
| `q` | 搜索词 | 空 |
| `cols` | 列 key 逗号分隔 | 视图默认 |
| `search` | 搜索字段 key 逗号分隔 | 视图默认 |
| `ff` | 筛选字段 key 逗号分隔 | 视图默认 |
| `density` | `standard` / `compact` | 视图默认 |
| `sort` | `field:ASC\|DESC` 逗号分隔 | 视图默认 |
| `f` | URL 编码的筛选树 JSON | 无 |
| `page` | ≥1 整数 | 1 |
| `size` | 10/20/50/100 | 10 |
| `sel` | 当前页行 id 逗号分隔 | 空 |
| `overlay` | `view-config` / `filter` / `bulk-edit` / `transition` / `delete` | 无 |
| `tab` | `columns` / `search` / `filter` | `columns` |

规则：

- 所有写入使用 `replace`，条件变化重置 `page=1` 并清空 `sel`。
- `page` 超出页数时收敛到最后一页；非法 `size/sort/overlay` 丢弃。
- 与视图默认值相同的配置不写入 URL，避免脏标记误判。
- `sel` 只保留当前页 id；翻页、类型/视图切换、排序、页大小变化清空选择。

## 4. 视图

| 视图 | id | 谓词 | 默认排序 |
|---|---|---|---|
| 研发待办 | `dev` | 无 | `update_time DESC` |
| 我的事项 | `mine` | `assignee_id = 当前用户` | `priority ASC` |
| 本周到期 | `week` | `end_time ∈ [今天, 下周一)` | `end_time ASC` |
| 阻塞风险 | `blocked` | 有 `risk` 字段时 `custom.risk = 高风险`，否则 `status = blocked` | `priority ASC` |

- 已保存视图来自 `pmViewApi.list`，按 id 作为 `view`。
- 配置优先级：URL 覆盖 → 已保存视图 → 内置视图 → 字段布局 → 硬默认。
- 脏标记比较 `{cols, search, ff, density, sort, filter}`；`q/page/size/sel/overlay` 不算。
- 保存配置：已保存视图原地更新；内置视图按同名 + 同 typeCode 创建/更新后切到数字 id。
- 视图配置存 `PmSavedView.columns` 的第一个对象：

```json
{ "version": 1, "listFields": [], "searchFields": [], "filterFields": [], "density": "standard", "sort": [], "filterTree": { "logic": "AND", "children": [] } }
```

## 5. 搜索与筛选

### 5.1 搜索

- 350ms 防抖；Enter 立即；URL `q`。
- 配置字段默认 `title,itemKey,assignee_id,description`。
- 映射：`title/description` → `LIKE`；自定义文本 → `custom.<key> LIKE`；`itemKey` 解析编号 → `item_no EQ`；负责人姓名精确匹配 → `assignee_id IN`。
- 无法映射的搜索字段跳过；至少产生一个条件才发送搜索组。

### 5.2 筛选构建器

- 字段只来自 `ff`；根与条件组各一个 AND/OR；最多 2 层。
- 操作符按字段类型：文本（包含/不包含/等于/不等于/为空/不为空）、枚举（属于/不属于/是/不是/为空/不为空）、用户、日期（等于/早于/晚于/区间/今天/本周/为空/不为空）、数字。
- 值编辑器：多值、单值、区间、无值；切换字段/操作符时重置值。
- 缺值/区间不完整阻止应用并显示摘要。
- 预计匹配数：草稿 QuerySpec + `pageSize=1`，400ms 防抖。
- 快捷筛选：我的工作项、本周到期、阻塞风险、未分配。
- 查询映射：`NOT_CONTAINS → NOT_LIKE`；日期用 `BETWEEN/LT/GT`；枚举/用户提交 key/id。

## 6. 列表与批量

### 6.1 列

- 默认 8 列：编号、类型、标题、状态、优先级、负责人、截止时间、故事点。
- 列目录 = 系统/伪列 + 当前项目字段；缺失自定义字段生成缺省列并渲染 `—`。
- 标题列固定显示；列顺序即展示顺序；密度 `compact/standard`。
- 单元格：编号等宽、类型标签、状态 pill、优先级文案、负责人显示名、截止日期、故事点数字；长文本省略。

### 6.2 批量

- 批量动作来自 `batch-action-configs`；默认开启编辑/流转，删除默认关闭。
- 批量编辑：字段 = 配置白名单 ∩ 列目录；支持清空；可先 dry-run 预览再执行（不强制）；返回 success/skipped/failed 明细。
- 批量流转：目标状态并集；优先 `toStatus`；多可达/非法流转由后端返回 SKIPPED；展示原因。
- 批量删除：逐条调用删除；数量确认；展示成功/失败；失败项保留选择。
- 上限/角色/启停在执行前校验；后端错误原样展示。

## 7. 状态与异常

| 状态 | 触发 | 表现 |
|---|---|---|
| 空 | 查询无结果 | 保留头/工具栏/类型导航；`没有匹配的工作项`；清空搜索/筛选入口 |
| 加载 | 首次加载 | 6~8 行骨架，保留头部 |
| 失败 | 非 403 错误 | `工作项加载失败` + 重试 |
| 无权限 | 403 / 20002 | `NoPermissionState`；隐藏新建、选择、批量、写操作 |
| 密集 | `density=compact` | 36px 行高 |
| 长文本 | 标题过长 | 单行省略 + title 提示 |
| 筛选态 | `f` 存在 | chip 行 + 筛后数量 |

异常：版本冲突 `21033`、批量超限 `21034`、动作禁用 `21035`、字段不可批量 `21036`、跨项目 `21037` 均按后端消息展示；dry-run 不写库。

## 8. 已知偏差

1. 原型默认列的故事点/风险/迭代在多数项目不存在，按缺省列显示 `—`。
2. 批量编辑默认只有 `priority/assignee_id/module_id/end_time`；自定义字段需 `batch_editable=1`。
3. 批量删除默认关闭，设置页在后续阶段；本轮实现弹层与门禁。
4. 无项目级角色接口，只读态由 403 驱动。
5. 批量流转多可达时返回 SKIPPED，需后续指定 transitionId。
6. 状态/优先级按数据库字典序排序，非原型语义顺序。
7. 已保存视图无个人/共享隔离。
8. itemKey/负责人不支持自由模糊搜索。
9. 「管理事项类型」「导入/导出」「保存视图弹层」「快速预览」不在本轮。

## 9. 验收标准

| 编号 | 标准 |
|---|---|
| AC-01 | 全部工作项与类型切换写入 URL，列表查询正确（全部不带 typeCode） |
| AC-02 | 类型导航显示计数，合计等于全部工作项 |
| AC-03 | 视图切换改变列/排序/谓词；配置变化显示脏点 |
| AC-04 | 列配置可勾选/上下移/恢复；变更即时预览并重绘表格，保存后落库并写入 URL |
| AC-05 | 搜索字段至少 1；占位与范围提示同步 |
| AC-06 | 筛选字段限制生效；2 层 AND/OR、操作符、值编辑器与表达式正确 |
| AC-07 | 缺值阻止应用并提示；修复后消失 |
| AC-08 | 排序三态 + Shift 多列；分页 10/20/50/100 与跳页；条件变化回第 1 页 |
| AC-09 | 选择当前页、批量栏、翻页/切换清空选择 |
| AC-10 | 批量编辑 dry-run/执行与逐条结果；清空值可用 |
| AC-11 | 批量流转展示 from→to 与 SKIPPED/FAILED 原因 |
| AC-12 | 批量删除确认数量、逐条结果、失败保留 |
| AC-13 | 403 无权限态隐藏写操作；空/错/加载/密集/长文本稳定 |
| AC-14 | 1440 与 1280 默认列无横向滚动 |
| AC-15 | URL 刷新/分享保留视图、搜索、筛选、排序、分页、选择 |
