## 2. 必须一致

1. 头部顺序：标题 → 项目 → 视图 → 总数 → 更新时间；右侧操作区保留新建入口（导入/导出后续）。
2. 视图页签：研发待办、我的事项、本周到期、阻塞风险；配置变更显示脏点。
3. 工具栏：搜索（字段范围）、筛选、显示、排序、密度、总数。
4. 默认 8 列：编号、类型、标题、状态、优先级、负责人、截止时间、故事点；标题固定显示。
5. 筛选构建器：字段/操作符按类型、根与组 AND/OR、最多 2 层、表达式预览、缺值阻止应用。
6. 分页：10/20/50/100，默认 10；页码/跳页/页大小写入 URL；条件变化回第 1 页。
7. 选择仅当前页；批量栏含批量编辑、状态流转、删除（启用时）。
8. 批量编辑：白名单、设置/清空、影响预览、逐条结果。
9. 空/加载/失败/无权限/密集/长文本状态稳定，1440 与 1280 无横向滚动。
10. 截止时间 key 统一 `end_time`；Shift 多列排序写入 `sort=field:ASC,...`。

## 3. 允许差异

| 差异 | 原因 |
|---|---|
| 故事点/风险/迭代列缺省显示 `—` | 当前项目可能未配置对应自定义字段 |
| 批量编辑字段集合以动作配置白名单为准 | 后端默认白名单与原型样例不同 |
| 批量删除默认不可见 | 动作默认关闭，设置页后续实现 |
| 导入/导出/保存视图弹层/快速预览未提供 | 本阶段非目标 |
| 无权限态由 403 驱动 | 项目级角色未建模 |
| 状态/优先级按数据库字典序排序 | 原型为语义排序，后续后端增强 |
| 视图保存后共享给项目所有用户 | 现有保存视图接口无个人/共享隔离 |
| 原型的 `state=empty/loading/...` 演示参数不实现 | 以真实数据、density、sel 覆盖等价状态 |

## 4. 数据 profile

使用真实项目、类型、字段、状态与事项数据；无 fixture 注入。缺省字段按 `—` 展示。
