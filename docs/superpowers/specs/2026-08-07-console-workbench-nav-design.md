# 控制台工作台与导航调整

## 目标

登录后默认进入平台级工作台；通过顶栏产品目录进入产品；用户中心作为顶栏独立入口（不再挂在用户菜单，也不再提供系统设置入口）。

## 信息架构

| 区域 | 路径 | 二级 Tab |
|------|------|----------|
| 平台工作台 | `/workbench`（`/` 重定向至此） | 无 |
| 项目管理 | `/pm/projects`、`/pm/monitor`（进入产品默认 `/pm/projects`） | 项目、项目监控 |
| 用户中心 | `/user/*`（现有 UserLayout） | 自带左侧栏 |

## 顶栏

- Logo → `/workbench`
- 产品切换器：按路径解析当前产品；非产品页显示「选择产品」
- 管理员可见「用户中心」独立入口 → `/user/accounts`
- 用户菜单仅保留：账号设置、退出登录（移除用户中心、系统设置）

## 非目标

- 不拆分系统设置控制台
- 不新增未上线产品的真实路由页
