# 流水线第一期 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 控制台可配置 GitHub 仓库流水线（阶段列 DAG），手动运行 clone/构建/测试；执行编译为 Tekton，无集群时运行失败但定义可保存。

**Architecture:** `pipeline-core` 持有定义、凭证、Run 与工具链矩阵；控制面编译 DAG。前端 `modules/pipeline` 用 Naive 阶段列，不用 Vue Flow。

**Tech Stack:** Java 21、Spring Boot、MyBatis-Plus、SQLite、Vue 3、Naive UI、Vitest、JUnit 5。Tekton 经 kubeconfig（本计划先完成控制面与编译器；集群 profile 可随后接）。
