## 3. 必须一致（A2）

- [x] 左侧项目导航顺序：原型总览 → 工作项类型 → 全部工作项 → 7 个启用类型 → 管理事项类型 → 协作 → 配置。
- [x] 类型导航显示名称、自定义标记与数量；数量合计等于全部工作项。
- [x] 全局 header 跨全屏：左侧产品选择（品牌 + 下拉，8 个产品，项目管理为当前项）、当前产品名称、面包屑（不含产品名）、右侧全局搜索、帮助 / 通知 / 账号；侧栏从 header 下方开始且只展示菜单。
- [x] 不设页面级页头：类型标题只保留在侧栏高亮与无障碍标题中，列表页不展示项目 / 视图名 / 总数 / 更新时间行。
- [x] 视图页签行：研发待办、我的事项、本周到期、阻塞风险、保存视图；右侧导入 / 导出 / 新建（只读态仅导出）。实现侧导入/导出属后续阶段，本轮只落「新建」，见 `20261022-pm-list-workbench/changes.md` 偏差 19。
- [x] 工具栏：搜索（含 N 个字段范围）、筛选、显示、排序、密度、结果数；筛选唯一入口是工具栏「筛选」，不设「+ 添加筛选」条件行。
- [x] 条件行只在已应用筛选时出现，展示条件 chip、清空与筛后条数。
- [x] 表格列由视图配置决定，默认：编号、类型、标题、状态、优先级、负责人、截止时间、故事点。
- [x] 选中后底部批量栏：批量编辑、状态流转、导出、删除、取消。
- [x] 视图配置抽屉三个页签：显示列、搜索字段、筛选字段。
- [x] 批量编辑弹层：字段白名单、设值/清空、影响预览、跳过提示、校验失败。
- [x] 导入三步：上传文件 → 字段映射 → 校验与执行。
- [x] 导出范围三选一与字段勾选。
- [x] 批量操作配置表格列：动作、启用、允许角色、单次上限、确认方式、配置。
- [x] 筛选构建器：字段选择、操作符随字段类型变化、值编辑器、根 AND/OR、条件组 AND/OR、表达式预览。
- [x] 条件组最多 2 层，一个组只能一种关系；缺值条件禁止应用并显示汇总。
- [x] 详情双栏：左侧标题/描述/活动/评论，右侧高频属性。
- [x] 标题、描述、属性可编辑；编辑态有底部保存条；状态流转只展示允许目标。
- [x] 活动/评论分页签；评论可发表；只读成员无写操作；未保存返回二次确认。
- [x] 描述阅读态渲染 Markdown；编辑态提供编辑/预览页签与工具栏；评论共用渲染器。
- [x] HTML 先转义后渲染；链接仅允许 http/https/mailto；不支持原始 HTML。
- [x] 顶部页签顺序：详情 / 操作记录 / 评论；默认详情；右栏属性跨页签常驻。
- [x] 编辑态只保留详情页签并提示保存后可查看其他页签。
- [x] 阅读态点击右栏字段打开内联编辑器；状态/优先级等选项菜单选中即保存；日期/数字/标签行内保存。
- [x] 状态内联更新只允许合法流转，非法目标置灰并标注原因。
- [x] 标题、描述、类型、报告人、模块、父事项、修复版本、环境、关注者均可单字段更新。
- [x] 每次字段变更追加操作记录；完整编辑按字段逐条记录；评论追加记录；记录数量实时更新。
- [x] 操作记录默认最新在前并分页；支持每页 5/10/20 条、页码与翻页；新增记录出现在第一页顶部。
- [x] 列表分页每页 10/20/50/100，默认 10；页码、跳页与每页条数写入 URL；翻页清空选择。
- [x] 视图页签行、工具栏、条件行与分页使用同一总数；空态显示 0。
- [x] 导出范围三选一与字段勾选可交互；全部、当前查询、已选的数量互相区分。
- [x] 截止时间字段 key 为 `end_time`，覆盖列、筛选、排序、批量、导入导出与详情内联。
- [x] Shift+点击表头追加多列排序，URL 使用逗号分隔。
- [x] 只读状态下写操作弹层、`edit=1` 与 `inline=*` 均不可用。
- [x] 评论与快速预览使用 Markdown 渲染器；评论发表后计数与列表立即刷新。
- [x] 批量栏与行操作遵守批量动作启停；默认关闭的删除不可发起。
- [x] 事项不存在时展示 404 态。
- [x] 危险操作二次确认并写明数量。
- [x] 1440×900 与 1280×800 下无横向滚动，长标题省略。
