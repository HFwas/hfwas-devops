## 1. 登录与导航

1. 打开平台地址，跳转到 Keycloak 登录页。
2. 输入账号密码登录，回到控制台。
3. `/workbench` 为工作台，可查看快捷入口、最近访问与我的事项。
4. 顶部产品切换器切换 8 个产品；右上角可切换租户、查看站内信与用户设置。

| 入口 | 路径 |
|------|------|
| 工作台 | `/workbench` |
| 用户管理 | `/user/accounts` |
| 个人设置 | `/user/settings` |

## 2. 项目管理

1. 进入 `/pm/projects`，新建项目（编码、名称）。
2. 在项目设置中启用事项类型（需求/任务/缺陷）。
3. 进入事项列表 `.../items/:typeCode`，新建事项并填写字段。
4. 在详情页查看/编辑字段、评论、关联、活动。
5. 在看板 `.../board/:typeCode` 拖拽事项改变状态。
6. 在 `.../settings/workflow/:typeCode` 配置状态与流转。
7. 在事项列表使用导入/导出（下载模板 → 预览 → 导入）。

## 3. 流水线

1. 进入 `/pipeline/pipelines`，点击新建。
2. 填写名称，绑定 Git 仓库、分支与凭证。
3. 添加阶段与任务，选择任务类型、命令、参数与资源限制。
4. 保存后点击运行，填写运行时参数。
5. 在运行详情 `/:pipelineId/runs/:runId` 查看任务状态与日志；可取消或审批。
6. 在 `/pipeline/credentials` 管理凭证，在 `/pipeline/task-kinds` 查看任务市场。

## 4. 容器平台

1. 进入 `/container/clusters`，纳管集群（kubeconfig）。
2. 进入集群详情，按命名空间浏览节点、Pod、Deployment、StatefulSet、Service、ConfigMap、Secret、PVC、StorageClass。
3. Pod 详情可查看日志、YAML、打开终端、上传/下载文件。
4. Deployment 详情可扩缩容、重启、编辑环境变量/卷/YAML。
5. 在 `/container/registries` 管理镜像仓库并浏览 project/repo/artifact。
6. 在 `/container/helm` 上传 chart、查看 release，执行安装/升级/回滚。
7. 在 `/container/images` 搜索镜像。

## 5. API 测试

1. 进入 `/api-test/definitions`，新建接口定义（路径、方法、参数、响应）。
2. 在详情页使用调试工作台发送请求，查看响应、耗时、断言与脚本日志。
3. 可粘贴 cURL 导入请求。
4. 在 `/api-test/environments` 维护环境与变量。
5. 在 `/api-test/collections` 创建集合、添加接口、调整顺序，触发批量运行并查看结果。
6. 在详情页查看调试历史。

## 6. 文档生成

1. 进入 `/docgen`。
2. 选择格式（Word/Excel/PPT/图片/Markdown/PDF）、文件名与内容参数。
3. 单文件生成直接下载；批量生成选择格式、大小、数量后生成到目录。
4. 生成结果按 `{格式}_{大小}_{基础名}_{序号}` 命名。

## 7. 文件解析

1. 进入 `/file-parser`。
2. 上传 DOCX/PPTX/XLSX/PDF/图片/TXT。
3. 查看文本提取、OCR 或压缩结果。

## 8. 图片处理

1. 进入 `/image`。
2. 上传图片创建会话。
3. 查看预览与元数据。
4. 选择目标格式、质量与尺寸执行转换。
5. 下载结果；在历史记录中查看最近转换。

## 9. 用户与租户（管理员）

1. `/user/accounts`：创建用户、重置信息、删除用户。
2. 租户管理：创建租户、维护成员与角色。
3. 日志：查看登录日志、操作日志。
4. 站内信：管理员可群发/定向发送。
5. 集成：配置身份连接器（LDAP 等），测试连接并同步。
6. 通知渠道：配置并测试。

## 10. 常见问题（待补充）

| 问题 | 处理 |
|------|------|
| 登录后无权限 | 确认平台角色与租户成员关系 |

| 文件解析/生成失败 | 检查文件格式、大小与服务依赖 |
