## 5. 回滚

| 场景 | 操作 |
|------|------|
| 应用回滚 | `helm rollback` 到上一版本 |
| 镜像回滚 | 切换到上一不可变 tag |
| 数据回滚 | 停止写入 → 恢复备份 DB → 启动；注意 schema 版本兼容 |
| 部分功能回滚 | 通过配置/任务类型启停，避免直接回退数据库 |
